## 🎨 通用参数说明

### Midjourney 参数解释：
- `--ar 16:9`: 设置宽高比为 16:9（适合 Twitter/社交媒体）
- `--style raw`: 使用原始风格，减少 AI 过度艺术化
- `--v 6`: 使用 Midjourney v6 模型（最新版本）
- `--s 50`: 降低风格化程度（可选，数值 0-1000，越低越接近 prompt）

### DALL-E 3 使用建议：
1. 在 ChatGPT Plus 中使用（需要订阅）
2. 直接粘贴 prompt，AI 会自动优化
3. 可以要求调整细节（"make the text bigger", "use darker background"）
4. 每次生成 1 张图，可以重新生成不同版本

### Stable Diffusion 使用建议：
1. 推荐使用 SDXL 模型
2. Negative prompt 推荐：`blurry, low quality, distorted text, watermark, signature, cluttered, messy layout`
3. Steps: 30-50
4. CFG Scale: 7-9
5. Sampler: DPM++ 2M Karras 或 Euler a

## 🚀 快速开始

### 如果你用 Midjourney：
1. 加入 Midjourney Discord
2. 输入 `/imagine` 命令
3. 粘贴上面的 prompt
4. 等待生成（约 1 分钟）
5. 点击 U1-U4 放大你喜欢的版本

### 如果你用 DALL-E 3：
1. 打开 ChatGPT Plus
2. 选择 GPT-4 模式
3. 直接粘贴 prompt
4. 等待生成（约 30 秒）
5. 右键保存图片

### 如果你用本地 HTML 版本：
1. 打开桌面上的 `marketgo-day2-visuals-index.html`
2. 点击"打开图片"
3. 使用截图工具截取（1200x675px）
4. 或右键"将图片另存为"

## 📐 尺寸建议

### Twitter/X 最佳尺寸：
- **单图：** 1200x675px (16:9)
- **多图：** 1200x1200px (1:1) 或 1200x675px (16:9)
- **格式：** PNG 或 JPG
- **文件大小：** < 5MB

### Instagram 最佳尺寸：
- **Feed 帖子：** 1080x1080px (1:1)
- **Reels：** 1080x1920px (9:16)
- **Story：** 1080x1920px (9:16)

### LinkedIn 最佳尺寸：
- **帖子图片：** 1200x627px 或 1200x1200px
- **格式：** PNG 或 JPG

---

## 🎯 使用提示

1. **HTML 版本最快：** 如果你赶时间，直接用桌面的 HTML 文件截图
2. **AI 生成更灵活：** 如果你想调整颜色、布局、文字，用 AI prompt
3. **混合使用：** HTML 截图后，可以用 Figma/Canva 再编辑
4. **统一风格：** 建议所有图片使用同一种方法生成，保持视觉一致性

---

## ⚠️ 注意事项

- **文字清晰度：** AI 生成的图片有时文字不清晰，HTML 版本文字更清晰
- **品牌一致性：** 如果你有品牌色，记得在 prompt 中指定颜色代码
- **版权：** AI 生成的图片可商用，HTML 版本你可以自由使用
- **测试：** 发布前在手机上预览，确保文字在小屏幕上可读

---

**推荐方案：**
1. **最简单：** 用桌面 HTML 文件 → 截图 → 发布 ✅
2. **最灵活：** 用 AI prompt → 生成 → 微调 → 发布
3. **最专业：** HTML 截图 → Figma 编辑 → 加品牌元素 → 发布
