### Step 1: 复制 Prompt
```

```

### Step 2: 打开 Nano Banana
- 粘贴 prompt
- 点击生成

### Step 3: 调整（如果需要）
如果生成效果不满意，可以添加这些调整词：
- 文字太小 → 加 "large bold text"
- 不够清晰 → 加 "high contrast, sharp text"
- 颜色不对 → 加 "purple gradient from #667eea to #764ba2"

### Step 4: 下载
- 下载生成的图片
- 确保尺寸是 1200x675px（Twitter 最佳）
