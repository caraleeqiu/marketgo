# 封面拆解 · 把爆款封面拆成「视觉公式」

复刻的不是图，是**公式**。这一步把一张参考封面拆成 6 个可复用的维度，填进 `plan` 的 `reference_formula`。

> ⚠️ 拆解 = 提取**结构和风格**，不是抄内容。参考封面里的原始文字、人脸、品牌 logo、水印一律不进公式。

---

## 6 个拆解维度

### ① 版式类型 layout
封面的骨架。常见 5 类：

| 版式 | 特征 | 常见平台 |
|:---|:---|:---|
| 上字下图 | 标题在上 1/3，主体图在下 | 小红书 |
| 居中大字压图 | 大标题压在主体/背景上，文字是主角 | YouTube / 小红书 |
| 左图右字 / 左字右图 | 分栏，一边主体一边文字 | 小红书 / ins |
| 满版图 + 角标 | 整张是图，只在角上加小标签/数字 | ins / 小红书 |
| 分屏拼图 | 上下或左右拼两张图（before/after、对比） | YouTube / 小红书 |

### ② 构图与主体位置 composition
- 主体占画面比例（特写 / 半身 / 全身 / 小元素）
- 位置（居中 / 三分线交点 / 边缘留白）
- 视线 / 朝向（看镜头 / 看向文字 / 侧脸）
- 景深与背景虚化程度

### ③ 配色 color
- 主色 + 强调色 + 背景色（3 色以内说清）
- 冷暖倾向、饱和度高低
- 是否撞色 / 是否高级灰 / 是否单色调
- 文字色与背景的对比关系

### ④ 文字层级 text_hierarchy
- 主标题：字号、字重、字体风格（黑体力量感 / 衬线高级感 / 圆体亲和 / 手写感）
- 副标题 / 角标 / 标签：有没有、放哪
- 文字修饰：描边、底色块、阴影、高亮、关键词变色
- 文字与主体的叠压关系

### ⑤ 情绪钩子 emotion_hook
封面为什么让人想点：
- 夸张表情 / 强反应（YouTube 常见）
- 悬念、留白信息（「最后我才发现…」）
- 数字（「3 个」「7 天」「90%」）
- 痛点词 / 对比词（「踩坑」「翻车」「亲测」「before/after」）
- 利益点前置（「免费」「保姆级」「一篇搞懂」）

### ⑥ 平台味儿 platform_flavor
- 小红书：清新、真实、生活感、人设感
- Instagram：高级、氛围、色调统一、留白
- YouTube：高对比、强冲击、夸张、信息少情绪强

---

## 拆解输出示例

参考封面：一张小红书「3 个早起方法」封面 →

```
layout: 上字下图（标题占上 1/3，人物半身在下）
composition: 人物半身居中偏下，看向镜头，背景浅色虚化
color: 主色奶油白 + 强调色暖橙，低饱和，高级感
text_hierarchy: 主标题黑体加粗带白色描边 + 橙色底色块，"3" 字放大变色；无副标题
emotion_hook: 数字「3」+ 痛点词「早起困难户」
platform_flavor: 小红书 · 清新生活感
```

把这套公式填进 `plan.reference_formula`，再把用户的内容填进 `plan.user_content` —— 公式不变，内容全换。
