# 平台规格 · 三平台封面规范

封面复刻的第一件事：定平台 + 定规格。规格错了，后面全错。

---

## 小红书（笔记封面）

| 项 | 规范 |
|:---|:---|
| 比例 | **3:4 竖版**（也支持 1:1，但 3:4 是当前主流，默认用 3:4） |
| 像素 | 1080 × 1440 px |
| 标题区 | 上 1/3 或下 1/3，主体居中或偏上 |
| 标题字数 | 主标题 ≤ 15 字最佳，大字号、高对比、常带描边或底色块 |
| 风格味儿 | 清新生活感 / 真实感 / 氛围感；忌过度精修的「广告感」 |
| 点击率要素 | 痛点词、数字（「3 个方法」「踩过的坑」）、对比、人设感 |
| 安全区 | 顶部和底部各留 ~8% 边距，避免文字贴边 |

## Instagram（Feed 帖子封面）

| 项 | 规范 |
|:---|:---|
| 比例 | **4:5 竖版**（当前主流，默认）或 **1:1 正方形**（经典 grid） |
| 像素 | 4:5 → 1080 × 1350 px；1:1 → 1080 × 1080 px |
| 标题区 | 文字精简，常居中或压在主体上方/下方；很多封面甚至无字，纯视觉 |
| 标题字数 | 极简，主标题 ≤ 6 词 / ≤ 10 字；英文为主时注意字体调性 |
| 风格味儿 | 高级氛围感 / 统一色调 / 留白；强调 grid 整体协调 |
| 点击率要素 | 视觉冲击、色调统一、构图高级；情绪 > 信息 |
| 安全区 | 注意 grid 缩略图裁切，主体和文字别贴四边 |

> 注：ins Reels 封面是 9:16，本 Skill 默认做 Feed 封面（4:5 / 1:1）。用户明确要 Reels 封面时用 9:16（1080 × 1920）。

## YouTube（视频缩略图）

| 项 | 规范 |
|:---|:---|
| 比例 | **16:9 横版** |
| 像素 | 1280 × 720 px（最小），推荐 1920 × 1080 |
| 标题字数 | 文字**极大、极少**，3–5 个词；一眼能读完 |
| 风格味儿 | 高对比、强冲击、夸张表情、撞色；信息密度低但情绪密度高 |
| 点击率要素 | 夸张表情/反应、悬念、箭头/圈red 标注、对比（before/after）、大数字 |
| 安全区 | **右下角**会被视频时长戳遮挡 — 别放关键文字/主体；播放时**底部**会被进度条压住 |

## 自动判断平台

Agent 拿到参考封面后，按比例自动判断平台：

| 参考封面比例 | 判断平台 |
|:---|:---|
| 3:4 / 接近竖版偏方 | 小红书 |
| 1:1 / 4:5 | Instagram |
| 16:9 横版 | YouTube |
| 判断不了 / 用户另有目标平台 | 直接问用户 |

平台和规格确认后写进 `plan` 的 `platform` + `spec` 字段。
