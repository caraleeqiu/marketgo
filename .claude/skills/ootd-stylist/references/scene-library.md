# 场景库 · 10 个预设场景

场景是必须输入。每个场景有自己的穿搭基调、关键词和忌讳。Phase 02 先用这张表定调，再叠加 `style_profile` 和季节。

---

| 场景 | 穿搭基调 | 关键词 | 忌讳 |
|:---|:---|:---|:---|
| **通勤** | 利落、得体、不费力 | 西装、衬衫、直筒裤、乐福鞋 | 过度暴露、夸张印花、太休闲的运动装 |
| **约会** | 有记忆点、柔和或亮眼 | 连衣裙、针织、半裙、小高跟 | 过于正式、过于运动、全身黑沉闷 |
| **旅行** | 舒适、耐穿、出片 | 阔腿裤、卫衣、帽子、平底鞋 | 紧身不透气、高跟、易皱面料 |
| **运动** | 功能性、贴合、透气 | 运动套装、紧身裤、运动鞋 | 牛仔硬料、正装、配饰过多 |
| **派对** | 出挑、有光泽感、夸张 | 亮片、缎面、皮质、高跟 | 过于素淡、运动休闲、廓形过大显邋遢 |
| **面试** | 专业、保守、整洁 | 西装套装、衬衫、及膝裙、皮鞋 | 露肤、夸张配饰、高饱和撞色、破洞 |
| **居家** | 松弛、柔软、保暖 | 卫衣、家居服、针织、棉拖 | 紧身、硬料、繁复配饰 |
| **校园** | 青春、轻便、平价感 | 卫衣、牛仔、帆布鞋、双肩包 | 过于成熟、性感、奢华感 |
| **逛街日常** | 百搭、舒适、随性 | 牛仔裤、T恤、外套、小白鞋 | 太隆重、太正式 |
| **节日** | 应景、喜庆或主题化 | 主题色、配饰点缀、外套亮点 | 与节日氛围冲突的沉闷搭配 |

> 用户给的场景不在表内 → 按用户的自定义描述定调，参照最接近的预设场景。

## 季节叠加

季节（可选输入）在场景基调之上调整单品的**厚薄、材质、层次**：

| 季节 | 调整 |
|:---|:---|
| 春 | 轻薄外套、单层、明快色 |
| 夏 | 短款、透气面料、少层次 |
| 秋 | 针织、风衣、叠穿层次 |
| 冬 | 厚外套、保暖内搭、靴子 |

用户没给季节 → 从场景推断（如「滑雪」必是冬），推断不了就问用户。

## 天气 / 地点

天气和地点并入「场景」一起理解（如「下雨天通勤」「海边度假」），影响鞋履选择、是否带外套、面料防水性等，不单列为 Slot 字段。
