# 产品溯源 · 给单品搜真实产品

Phase 03 的任务：把 `outfit_plan` 里选定套的文字单品（如「白色丝质衬衫」）变成真实产品 —— 产品图 + 名称 + 购买链接 + 参考价。它有两个作用：① 给 Phase 04 出图当视觉锚点；② 让用户能直接照着买。

---

## 搜什么

对每个 `selected_for_frame: true` 的套，逐个单品槽位（上装 / 下装 / 外套 / 鞋 / 包 / 配饰）搜电商产品。按单品的文字描述搜，结合 `style_profile` 的色系与气质收敛结果。

## 每个产品记录什么

| 字段 | 放哪 |
|:---|:---|
| 产品图 | `media`（`type: image`，`url`） |
| 产品名称 | `title` |
| 所属单品槽位 + 套名 | `subtitle`（如「基础百搭 · 上装」） |
| 购买链接 + 参考价 | `text`（用户可见可点） |
| 来源站点 / 单品类型 / 套名 | `tags` |

## 匹配标准

- **视觉接近**文字描述（版型、颜色、材质对得上）
- **风格调性一致** —— 跟 `style_profile` 的气质标签、`outfit_plan` 的 tier 不冲突
- **价格区间合理** —— 同一套内的单品价位大致协调，不要一件天价一件地摊

## 诚实 caveat（写进交付，不要瞒用户）

- 链接和价格来自**搜索当时**的结果，**不保证库存 / 价格实时准确**。
- 本 skill **不做下单 / 支付**，只给到购买链接为止。
- 链接有效性依赖搜索结果质量；失效的链接由用户自行甄别。

## 失败与降级

- **某个单品搜不到** → 该 card 用 `media.state=failed`，`text` 保留原文字描述，不阻塞其余单品。
- **runtime 无图片搜索能力** → `product_picks` 降级为「文字占位」：每张 card 仍按单品建条，`media` 不填，`text` 写文字描述，`tags` 标 `search unavailable`。`outfit_frame`（Phase 04）随之退回纯文字驱动出图。
