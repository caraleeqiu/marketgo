# 穿搭规则 · 风格 × 场景 → 单品组合

> 🛠️ **这是一版草稿，给后续修改用。** 穿搭是主观的，这里只给一套可运行的基础规则，用户可以按自己的审美随时改。

Step 2 用这套规则，结合 `style_profile`（气质标签 + 色系 + 版型）和 `scene-library.md` 的场景基调，出 3 套方案。

---

## 单品结构（每套方案的骨架）

每套穿搭固定 6 个槽位，缺的标「无」：

```
上装 top      下装 bottom    外套 outerwear
鞋 shoes      包 bag         配饰 accessories
```

---

## 配色规则（由 style_profile 的 color_palette 决定）

| 肤色/色系 | 推荐主色 | 慎用 |
|:---|:---|:---|
| 暖调 warm | 大地色、奶油色、橘调、暖红、卡其 | 冷蓝、冷紫、纯黑大面积 |
| 冷调 cool | 冷白、灰蓝、正红、莫兰迪、黑白 | 土黄、橘、暖棕 |
| 中性 neutral | 大部分色都可，以场景定 | 极端高饱和大面积 |

一套搭配遵循「主色 + 辅色 + 点缀色」三色内，点缀色出现在包或配饰。

## 版型规则（由 fit_preference + 身材比例决定）

- **修身**：突出线条，适合比例好或想显瘦 → 上紧下松或上松下紧，避免全身宽松
- **廓形**：遮肉、时髦感强 → 注意露出一处「窄」（脚踝 / 手腕 / 锁骨）避免显壮
- **利落**：直线条、硬挺面料 → 通勤面试首选

## 气质标签 → 穿搭方向

| 气质标签 | 方向 | 标志单品 |
|:---|:---|:---|
| 甜美 | 柔和、圆润、浅色 | 连衣裙、针织、碎花、芭蕾鞋 |
| 清冷 | 极简、冷色、留白 | 衬衫、直筒裤、黑白灰、尖头鞋 |
| 酷飒 | 硬朗、利落、暗色 | 皮衣、机车靴、廓形西装 |
| 温柔 | 顺滑、低饱和、垂坠 | 半裙、开衫、丝质、奶奶鞋 |
| 英气 | 中性、挺括、线条感 | 西装、马甲、衬衫、乐福鞋 |
| 元气 | 明快、活泼、撞色 | 卫衣、短裤、彩色、运动鞋 |
| 复古 | 怀旧、纹理、暖调 | 灯芯绒、格纹、波点、玛丽珍 |
| 优雅 | 高级、合身、克制 | 大衣、连衣裙、高跟、真丝 |

## 3 套方案的差异化原则

同一个「风格 × 场景」下，3 套必须拉开层次，不能是同一套的微调：

| Tier | 定位 | 怎么做 |
|:---|:---|:---|
| **基础百搭** | 安全、零失误、好驾驭 | 经典单品 + 中性色 + 标准版型 |
| **进阶亮点** | 有记忆点，但不冒险 | 在基础款上加一个亮点：一件特别单品 / 一个点缀色 / 一处叠穿 |
| **大胆尝试** | 风格化、出挑、敢穿 | 强风格单品 + 撞色或夸张廓形 + 配饰堆叠 |

## 硬约束

- **必含单品**：用户指定了必含单品 → 3 套都必须包含它，围绕它搭。
- **风格偏好**：用户指定了风格（如「美拉德」）→ 3 套都在该风格框架内做层次，不跑偏。
- **场景忌讳**：`scene-library.md` 里该场景的「忌讳」是红线，3 套都不能踩。
- **季节**：按 `scene-library.md` 的季节叠加规则调整厚薄材质。

每套配一句**搭配理由**（为什么这么搭、适合什么人），写进 `outfit_plan.options[].reason`。
