# 风格检测 · 三类主体各检测什么

Phase 01 的任务：把主体照片读成一份结构化的 `style_profile`。检测准不准，直接决定后面穿搭推荐准不准。

> 第一步永远是**判断主体类型**：真人 / 卡通虚拟形象 / 物体角色。类型决定检测哪些维度。

---

## 真人

| 维度 | 检测什么 | 影响 |
|:---|:---|:---|
| 脸型 | 圆 / 方 / 长 / 鹅蛋 / 心形 | 领型、配饰 |
| 身材比例 | 身高比例、肩胯关系、上下身比例 | 版型、腰线位置 |
| 肤色冷暖 | 暖调 / 冷调 / 中性 | 适配色系 |
| 五官浓淡 | 浓颜 / 淡颜 / 中间 | 风格强度（能不能驾驭夸张单品） |
| 气质标签 | 见下方标签库 | 穿搭方向 |

## 卡通虚拟形象

| 维度 | 检测什么 |
|:---|:---|
| 造型轮廓 | 圆润 / 尖锐 / Q 版 / 写实 |
| 配色 | 角色固有色 |
| 角色气质 | 见标签库 |
| 比例 | 头身比、体型 |

> 卡通主体的核心是**保留角色识别度** —— 检测出固有色和轮廓，穿搭不能盖掉角色本身。

## 物体角色

物体没有脸型身材，换一套维度：

| 维度 | 检测什么 |
|:---|:---|
| 体态轮廓 | 整体形状、可拟人化的「身体」结构 |
| 主色调 | 物体的主色 + 辅色 |
| 材质感 | 金属 / 绒毛 / 塑料 / 木质 …（影响穿搭材质呼应） |
| 造型气质 | 见标签库（萌 / 硬核 / 复古 …） |

> 物体角色做穿搭 = 拟人化处理。检测的是「这个物体当成一个角色，它是什么调性」。

---

## 气质标签库（三类通用）

`甜美` `清冷` `酷飒` `温柔` `英气` `中性` `元气` `复古` `优雅` `自然` `硬核` `萌`

一个主体可以有 1–2 个标签（如「清冷 + 利落」）。

## 输出统一格式

不管哪类主体，最终都收束成同一个 `style_profile`：

```
subject_type:  real_person / cartoon / object
key_features:  [对应类型的关键特征描述]
vibe_tags:     [1-2 个气质标签]
color_palette: warm / cool / neutral
fit_preference: 修身 / 廓形 / 利落
```

---

## 检测不确定怎么办

⚠️ **不硬猜。** 出现以下情况，停下来问用户补充，不要带着错误信息往下走：

- 图太糊 / 角度太偏 / 光线太差 → 要求重传清晰图
- 半身图缺下半身 → 可继续，但身材比例标注「未知」，并告知用户身材相关建议精度下降
- 主体类型判断不了（介于卡通和真人之间等）→ 直接问用户
- 多人入镜 → 要求用户指明 / 重传单人图（边界：不做多人）
