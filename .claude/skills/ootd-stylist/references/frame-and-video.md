# 出图与视频 · 首帧图 + 走秀视频

Phase 03 和 Phase 04 的执行规格。本 skill 结构独立、引擎规格自包含，不依赖 seedance skill 的文件。

---

## Phase 03 · 穿搭首帧图

**模型：** GPT 图像生成（主力）→ Banana 2（降级）。

**核心约束：一致性。** 把用户主体照片作为参考图传入，锁定主体识别特征，**只换服装**。

| 主体类型 | 出图方式 |
|:---|:---|
| 真人 | 强约束**长相 + 体型 + 发型**一致，只替换为选定穿搭；不改脸、不改身材 |
| 卡通虚拟形象 | 保留**角色固有色 + 轮廓 + 识别特征**，穿搭不能盖掉角色本身 |
| 物体角色 | 拟人化处理，保留**物体主色 + 材质 + 造型特征**，服装贴合物体体态 |

**出图 prompt 骨架：**

```
[参考图：用户主体照片]
保持主体的 [长相/体型/角色特征] 完全一致，仅替换服装为以下穿搭：
上装：[outfit_plan.selected.items.top]
下装：[bottom]　外套：[outerwear]
鞋：[shoes]　包：[bag]　配饰：[accessories]
姿势：全身正面站姿，T台走秀起势
画面：9:16 竖版，全身入镜，简洁走秀背景，光线均匀
[画质后缀：高清、锐利、服装细节清晰]
```

→ 等用户确认首帧满意后进入 Phase 04。出图失败 → 切 Banana 2。

## Phase 04 · 走秀视频

**引擎：Seedance 2.0（即梦）。** 视频时长是结构变量，按时长分叉：

| 视频时长 | 生成方式 |
|:---|:---|
| **≤15s** | Seedance 单段直接生成 —— 贴合 Seedance 单次能力，默认路径 |
| **15–30s** | Seedance 出多段，按走秀节奏拼接到目标时长 |

整条链路围绕 **Seedance 2.0 单次约 ≤15s + GPT 图像出图**的能力边界设计。超过 15s 必须走拼接，换引擎 = 前面的 prompt 和材料清单可能作废。

**视频风格调色板（`video_style`）：** 在 Phase 02 确认门确认；用户不指定则由场景 + `style_profile` 推断。

| 风格 | 背景 / 打光 / 调色 | 适配场景 |
|:---|:---|:---|
| 时尚大片 | 极简纯色背景、专业硬光、冷调高级灰 | 派对 / 面试 / 通勤 |
| 街拍随性 | 城市街道、自然光、生活感调色 | 逛街 / 旅行 / 校园 |
| 居家温馨 | 室内暖光、柔焦、暖调 | 居家 |
| 复古胶片 | 颗粒感、暖黄、怀旧褪色 | 复古风偏好 |
| 小清新 | 高调明亮、清爽冷白、低饱和 | 约会 / 校园 |
| 赛博霓虹 | 夜景、霓虹光、高饱和撞色 | 派对 / 夜店 |

`video_style` 决定背景、打光、调色、镜头语言；走秀动作本身不变。首帧图（Phase 03）的背景调性应与选定风格保持一致，保证首帧到视频的视觉连贯。

**拼接说明（15–30s 路径）：** 按走秀节奏切段，每段 ≤15s，剪辑点放在动作衔接处 —— 入场段（由远及近）→ 近景展示段 → 转身段。每段都以 `outfit_frame` 形象为锚点，保证主体和穿搭跨段一致。

**视频规格：**

```
动作：走秀（runway walk）—— 主体正面走向镜头，行至近景转身展示穿搭背面/侧面
镜头：固定机位 + 主体由远及近，或缓慢推镜
时长：≤15s 单段 / 15–30s 拼接
画幅：9:16 竖版
输入锚点：Phase 03 的 outfit_frame 首帧图
音画同出：自动带 BGM / 脚步音效（短视频默认，不单独处理）
```

**走秀动作描述（传给引擎）：**

```
主体保持 outfit_frame 的形象，从画面深处沿 T 台直线走向镜头，
步态自然自信，行至近景定点，转身一圈展示穿搭整体，
全程服装与主体形象保持一致。
```

## 降级链

```
Phase 03 出图：GPT 图像生成
  └─ 失败 → Banana 2
       └─ 仍失败 → 告知用户，停在 outfit_plan（已有穿搭清单）

Phase 04 出视频：Seedance 2.0
  ├─ 15–30s 拼接失败 → 退回 ≤15s 单段
  └─ 单段仍失败 → ootd_video 标 degraded
       └─ 保留 outfit_plan 清单 + outfit_frame 首帧图作为交付物
```

⚠️ 即使视频失败，用户至少拿到「穿搭方案清单 + 首帧图」—— 核心交付不完全落空。
