# 出图与视频 · 首帧图 + 走秀视频

Phase 04 和 Phase 05 的执行规格。本 skill 结构独立、引擎规格自包含，不依赖 seedance skill 的文件。

---

## Phase 04 · 穿搭首帧图

**模型：** GPT 图像生成（主力）→ Banana 2（降级）。

**核心约束：一致性。** 两类参考图一起喂：用户主体照片锁主体识别特征，`product_picks` 的产品图锁服装外观，**只换服装**。

| 主体类型 | 出图方式 |
|:---|:---|
| 真人 | 强约束**长相 + 体型 + 发型**一致，只替换为选定穿搭；不改脸、不改身材 |
| 卡通虚拟形象 | 保留**角色固有色 + 轮廓 + 识别特征**，穿搭不能盖掉角色本身 |
| 物体角色 | 拟人化处理，保留**物体主色 + 材质 + 造型特征**，服装贴合物体体态 |

**出图 prompt 骨架：**

```
[参考图 1：用户主体照片] [参考图 2..N：product_picks 里该套各单品的产品图]
保持主体的 [长相/体型/角色特征] 完全一致，把服装替换为参考图里的产品：
上装/下装/外套/鞋/包/配饰 —— 按 product_picks 对应产品的外观还原
（product_picks 里 media.state=failed 的单品退回 outfit_plan 的文字描述）
姿势：全身正面站姿，T台走秀起势
画面：9:16 竖版，全身入镜，背景调性与所选 video_style 一致，光线均匀
[画质后缀：高清、锐利、服装细节清晰]
```

→ 给每个 `selected_for_frame` 的套各出一张，写成 `outfit_frame` grid 里的 card。出图失败 → 切 Banana 2。

## Phase 05 · 走秀视频

**引擎：Seedance 2.0（即梦）。** 按 `selected_for_video` 的套数 N 分叉：

| 套数 N | 生成方式 |
|:---|:---|
| **N = 1** | 单段走秀，Seedance 单段直出（≤15s） |
| **N = 2-3** | 换装 montage —— 每套一个 segment，Seedance 多段拼接（最长 30s） |

整条链路围绕 **Seedance 2.0 单次约 ≤15s + GPT 图像出图**的能力边界设计：一套穿搭 = 一个 segment，刚好落在单次能力内。

**换装 montage 结构（N = 2-3）：**

- 每个 segment 以对应套的 `outfit_frame` card 为锚点，走一小段走秀 / 定格展示。
- segment 接缝处加**特效转场**：卡点切换 / 旋转 / 定格 / 滑动 —— 记进 `ootd_video.transition_style`。
- 全片铺**一条连续 BGM**（不是每段各自带音），卡点对齐换装节奏 —— 记进 `ootd_video.bgm`。

**视频风格调色板（`video_style`）：** 在 Phase 02 确认门确认；用户不指定则由场景 + `style_profile` 推断。

| 风格 | 背景 / 打光 / 调色 | 适配场景 |
|:---|:---|:---|
| 时尚大片 | 极简纯色背景、专业硬光、冷调高级灰 | 派对 / 面试 / 通勤 |
| 街拍随性 | 城市街道、自然光、生活感调色 | 逛街 / 旅行 / 校园 |
| 居家温馨 | 室内暖光、柔焦、暖调 | 居家 |
| 复古胶片 | 颗粒感、暖黄、怀旧褪色 | 复古风偏好 |
| 小清新 | 高调明亮、清爽冷白、低饱和 | 约会 / 校园 |
| 赛博霓虹 | 夜景、霓虹光、高饱和撞色 | 派对 / 夜店 |

`video_style` 决定背景、打光、调色、镜头语言；走秀动作本身不变。首帧图（Phase 04）的背景调性应与选定风格一致，保证首帧到视频的视觉连贯。

**视频规格：**

```
动作：走秀（runway walk）—— 主体正面走向镜头，行至近景转身展示
结构：N=1 单段 / N=2-3 换装 montage（每套一段 + 接缝转场）
时长：单段 ≤15s / montage 拼接最长 30s
画幅：9:16 竖版
输入锚点：Phase 04 的 outfit_frame 各 card
BGM：一条连续 BGM 铺满全片，卡点对齐换装节奏
转场：换装接缝处加特效转场
```

**走秀动作描述（传给引擎，单个 segment）：**

```
主体保持对应 outfit_frame card 的形象，从画面深处沿 T 台直线走向镜头，
步态自然自信，行至近景定点，转身一圈展示穿搭整体，
全程服装与主体形象保持一致；段尾留出转场衔接点。
```

## 降级链

```
Phase 03 产品溯源：图片搜索
  ├─ 某单品搜不到 → 该 card media.state=failed，保留文字描述
  └─ runtime 无搜索能力 → product_picks 降级为文字占位记录

Phase 04 出图：GPT 图像生成
  └─ 失败 → Banana 2
       └─ 仍失败 → 该 card media.state=failed，不阻塞其余张

Phase 05 出视频：Seedance 2.0
  ├─ 换装 montage 拼接失败 → 退回单段（取首选那一套）
  └─ 单段仍失败 → ootd_video 标 degraded
       └─ 保留 outfit_plan + product_picks + outfit_frame 作为交付物
```

⚠️ 即使视频失败，用户至少拿到「穿搭方案清单 + 产品链接 + 首帧图」—— 核心交付不完全落空。
