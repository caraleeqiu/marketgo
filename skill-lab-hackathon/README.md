# skill-lab-hackathon

Workspace for Skill Hackathon submissions.

## Active skill

**`skills/plumber-xray-storyteller/`** — A composition skill that turns a plumber's
on-site photo into a 45–75s explainer video with AI-generated X-ray cutaway
animation + decay timeline, designed to be posted to social media by real
tradespeople (high trust: real photo as anchor, AI only fills in what cameras
can't see).

## Layout

```
ideation/                       Brainstorm + Marketplace research notes
skills/<skill-name>/
  SOP.md                        Human-written SOP (input to create-skill)
  SKILL.md                      Generated by create-skill
  artifacts/                    JSON schema definitions
  assets/                       Test inputs (photos, etc.)
```

## Workflow

1. Ideation → lock direction (done: X-Ray Storyteller)
2. Verify Marketplace overlap < 70%
3. Map atomic skills to compose
4. Hand-write SOP (Trending Dance template)
5. Feed SOP to `create-skill` → SKILL.md + schemas
6. Upload to Skill Marketplace, test on mv.land
